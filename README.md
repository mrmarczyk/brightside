# Brightside Crossing — terminal prototype

A scroll-driven, single-file web prototype: the sky heats up, a CRT expedition log
prints itself, and the signal cuts out at perihelion.

**Live:** https://mrmarczyk.github.io/brightside/

## Source

An adaptation of the short story **“Brightside Crossing” by Alan E. Nourse**,
first published in *Galaxy Science Fiction*, January 1956. The story is in the
public domain and is available at Project Gutenberg:

<https://www.gutenberg.org/files/49165/49165-h/49165-h.htm>

All quoted text in the expedition log comes from that edition. This prototype is
an unofficial adaptation, not affiliated with the author's estate or the publisher.

## Build

None. `index.html` is self-contained; the only external dependency is
[Tone.js](https://tonejs.github.io/) loaded from cdnjs for the audio bed.
